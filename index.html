01 — GAME

รู้จักเกมใน 1 นาที

เกมสงครามยึดพื้นที่บนเกาะหกเหลี่ยมลอยฟ้า 156 แผ่น — ผู้เล่นแต่ละคนถือเกาะบ้านของตัวเอง ปั้นกองทัพ แล้วชิงเกาะกลางที่ให้รายได้สองเท่า ไม่มีวันจบเกม (ตั้งใจออกแบบเป็นลูปสะสมไม่รู้จบ ไม่มีหน้าสรุปแพ้ชนะ)

1ป้อมเกิดเองบนที่ดินของผู้เล่น ทุก 3 วินาที ผลิตเหรียญทุกวินาที
2เดินชนเพื่อยกแล้วหิ้วไปวางชนป้อมเลเวลเดียวกัน = รวมร่างแรงขึ้น
3อัปเกรดด้วยเหรียญ: เทียร์ป้อม จำนวนป้อม เวลาโล่ — เพชรใช้กับของถาวร/สกิน
4เปิดสงครามโหมดมุมสูง เลือกป้อมร่วมยิง ถล่มฐานคนอื่น ปล้นบอทได้ค่าหัว
5ยึดเกาะกลางรายได้ ×2 ต่อช่อง — พื้นที่เดียวในเกมที่แย่งกันได้จริง
6Rebirthรีเซ็ตแลกโบนัสรายได้ถาวร แล้ววนใหม่ให้ไกลกว่าเดิม

เซิร์ฟเวอร์คนน้อยจะมี บอท AI สวมอวตาร+ชื่อคนจริง มาถือเกาะ เดินเล่น ทักผู้เล่น พิมพ์แชท และรบกันเองให้แมพคึกเสมอ (บอทแพ้คนได้เสมอ ตีฐานคนไม่แตกโดยกติกา) ผู้เล่นใหม่มีทัวร์สอนเล่นบังคับ 15 ขั้นพาเล่นครบลูปตั้งแต่ล็อบบี้

03 — STUDIO GUIDE

คู่มือแก้ของใน Studio

ทุกใบด้านล่างคือของที่ทีมแก้เองได้โดยไม่แตะโค้ด — กดการ์ดเพื่อกางรายละเอียด กดกล่องดำ (ชื่อ path) เพื่อคัดลอกชื่อไปวางในช่องค้นหาของ Explorer

กติกาทอง: แก้ตอนไม่ได้กด Play เท่านั้น (แก้ระหว่างเล่นทดสอบ = งานหายตอน Stop) · แก้เสร็จกด Play ดูของจริงหนึ่งรอบ · ข้อความที่ผู้เล่นเห็น = อังกฤษเสมอ · ไอคอนหนึ่งรูปหนึ่งความหมาย · ไม่แน่ใจถามก่อน
🔍

ไม่เจอการ์ดที่ตรงกับคำค้น — ลองคำอื่น หรือถามในกลุ่มทีมได้เลย

เกม · ตัวเลข · ระบบ

🎚️ ค่าเกม / ราคาตัวเลขทั้งเกมในไฟล์เดียว▸

ดับเบิลคลิกเปิด ข้างในคือ ชื่อค่า = ตัวเลข พร้อมคอมเมนต์ไทยทุกบรรทัด — แก้เฉพาะตัวเลขหลัง =

  • BOT_FILL_TO/BOT_MAX จำนวนบอท · BARRIER_DURATION เวลาโล่ · UPGRADE_TIER_COST ราคาอัปเกรด
  • DATA_MOCK = true ทำให้กด Play ใน Studio เป็น "ผู้เล่นใหม่" เสมอ ไม่แตะเซฟจริง (สลับ false ถ้าอยากเทสต์ด้วยเซฟตัวเอง — เกมจริงไม่โดนผลนี้)
ห้าม: แตะ CELL_COUNT และค่าที่ขึ้นต้น GAMEPASS_/DEVPRODUCT_ — เป็นรหัสอ้างอิงระบบเงินจริง
🎟️ โค้ดของขวัญแจกโค้ดกิจกรรมเอง▸

เพิ่มหนึ่งบรรทัดต่อหนึ่งโค้ดตามแบบในไฟล์: ชื่อโค้ด = { gems = 100, money = 5000 },

  • ชื่อโค้ด: อังกฤษพิมพ์ใหญ่+ตัวเลข ไม่มีช่องว่าง (ผู้เล่นพิมพ์เล็กได้)
  • คนละ 1 ครั้งต่อโค้ดถาวร — แจกรอบใหม่ = ตั้งโค้ดใหม่ · ลบบรรทัด = โค้ดหมดอายุ
สำคัญ: ไฟล์นี้จงใจอยู่ฝั่งเซิร์ฟเวอร์กันผู้เล่นส่องโค้ด — ห้ามย้าย และอย่าหลุดโค้ดก่อนเวลาแจก
📜 เควส / ราคาสกิน / ยานชื่อ เป้าหมาย รางวัล ราคา▸

แก้ชื่อ (อังกฤษ) คำอธิบาย ราคาเพชร เป้าหมาย/รางวัลเควสได้อิสระ

ห้ามเด็ดขาด: เปลี่ยน/ใช้ซ้ำ "เลข id" ของสกินและยาน — เซฟผู้เล่นจำของที่ซื้อด้วยเลขนี้ตลอดไป ของใหม่ = เลขถัดไปเสมอ
📢 ประกาศอัปเดตUpdate Log + ของขวัญเวอร์ชัน▸

เพิ่มรายการเวอร์ชันใหม่บนสุด (หัวข้อ+วันที่+bullet อังกฤษ) แล้วขยับ UPDATE_ID ใน GameConfig ให้ตรง (ของขวัญ: UPDATE_GIFT_GEMS/UPDATE_GIFT_MONEY)

ของขวัญรับได้เฉพาะเวอร์ชันปัจจุบัน คนละครั้ง — พลาดแล้วพลาดเลย (ตั้งใจให้คนตามอัปเดต)

อาร์ต · เสียง · เอฟเฟกต์

🔊 เสียงใส่เสียง/เพลงเองได้ทั้งเกม▸

ก้อน Sound ตั้งชื่อตามจุดใช้ มี Attribute Note อธิบายไทยว่าเสียงดังตอนไหน — วางรหัสเสียงในช่อง SoundId ก็จบ (ว่าง = เงียบเฉยๆ ไม่พัง)

  • เสียงสุ่มหลายแบบ: ก๊อปแล้วตั้งชื่อ Merge02…09 — เกมสุ่มเล่นเอง
  • เพลงในเกม: BgGame/BgGame2/BgGame3 สุ่มหมุนเวียนไม่ซ้ำเพลงติดกัน
  • แก้ id แล้วต้องออก-เข้าเกมใหม่ถึงได้ยิน
🏰 โมเดลป้อมเปลี่ยนหน้าตาป้อม 35 เลเวล▸

โมเดล Turret1–Turret35 วางแทนตัวเดิมได้เลย โดยรักษากติกา:

  • ชิ้น Base (PrimaryPart) 3×1×3 ล่องหน + Anchored ก้นโมเดลเสมอก้น Base
  • ชิ้นอื่น: Anchored ปิด, CanCollide ปิด, CastShadow ปิด, เชื่อม Base ด้วย WeldConstraint — ห้ามมี Weld เก่าติดจากไฟล์ import (ทำป้อมจมพื้น)
  • ป้าย TurretInfo ใต้ Base ต้องอยู่ และข้อความ Lv.X ต้องตรงเลขชื่อโมเดล
กันพลาด: ลบ/เปลี่ยนชื่อ template ชั่วคราวเกมไม่พัง — ระบบยืมเลเวลใกล้เคียงโชว์แทน
✨ เอฟเฟกต์ (FX)โล่ / รวมร่าง / อีเวนต์ / อุกกาบาต▸
  • BarrierFx โล่ครอบเซลล์ — ต้องมีชิ้น Shell (เกมยืดให้) ของแต่งใส่เป็นลูกของ Shell
  • MergeFx ตอนรวมร่าง — emitter/เสียงอิสระ จำนวนพ่นอยู่ Attribute EmitCount
  • EventFx ป้ายอีเวนต์เซลล์กลาง — PrimaryPart คือชิ้นฐาน เกมวางแนบพื้นให้
  • CannonFx อุกกาบาต (Meteor Tier1–3) + ระเบิด (Bomb) — เกมย่อขยายพอดีพื้นที่เอง

เกมอ่านสดทุกครั้งที่ใช้ — วางของใหม่แล้วกด Play เห็นเลย

🌸 สกินพื้นที่Skin2–Skin9▸
  • PrimaryPart ชื่อ Tile = แผ่นทั้งก้อน (เกมยืดเท่าเซลล์จริง) ชิ้นอื่นวางเทียบผิวบน Tile
  • ชิ้นชื่อ Cap = พื้นหญ้าที่ถูกย้อมสีสถานะ — ห้ามเปลี่ยนชื่อ
  • ทุกชิ้นปิด CanCollide/CanQuery/CanTouch · ของสูงอยู่วงริมแผ่น กลางแผ่นคือเขตวางป้อม (ของแบน ≤ 0.5 เท่านั้น)
กติกาดีไซน์: สกินห้ามกลบสีสถานะ (ทอง/ส้ม) และแต่ละสกินต้องมีเอกลักษณ์ prop ของตัวเอง ไม่ใช่ย้อมสีของสกินอื่น
🛹 ยานพาหนะ / อนิเมชันบอร์ด 4 แบบ + ท่าขี่▸

Vehicle1–4 — PrimaryPart เป็นชิ้นล่องหนชื่อ Root แกนตรง แล้ว weld เมชทั้งหมดเข้ากับมัน ทุกชิ้นปิด collide + massless

RideIdle/RideMove/RideAir — วางรหัสอนิเมชันของกลุ่มในช่อง AnimationId

06 — DANGER ZONE

โซนห้ามแตะ

แตะแล้วเกมพังทันที — ห้ามแก้ไม่ว่ากรณีใด:
  • ServerScriptService › Network และ ReplicatedStorage › Network — โค้ดสร้างจากเครื่องมือ แก้มือ = ผู้เล่นหลุดยกเซิร์ฟเวอร์
  • ServerScriptService › Services ทั้งโฟลเดอร์ — ระบบเกม (อยากได้อะไรบอก dev)
  • workspace › Areas — แผ่นเกาะจริง 156 แผ่น มีข้อมูลฝังทุกแผ่น
ของคนอื่น: workspace › VFX คือพื้นที่ทีม VFX ที่ทำงาน live — ใครไม่ใช่เจ้าของห้ามแตะ/ลบ

ของตกแต่งแมพ (workspace › Environment) ล็อคกันคลิกพลาดไว้ — แก้ผ่าน Explorer แล้วล็อคคืนเสมอ
